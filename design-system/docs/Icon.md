# Icon

Line icon set drawn in the SF Symbols style (24 viewBox, 2pt stroke, round caps). Inherits `currentColor`. Names: `chevron-right`, `chevron-left`, `chevron-down`, `plus`, `search`, `gear`, `bubble`, `person`, `camera`, `qr`, `trash`, `check`, `check-double`, `mic`, `arrow-up`, `pencil`, `lock`, `bell`, `globe`, `key`, `shield`, `doc`, `share`, `x`, `ellipsis`, `antenna`, `link`.

```tsx
<Icon name="qr" size={20} />
```

Most components take an `icon`/`iconColor` prop and render this internally — reach for `Icon` directly only in custom compositions.
