# OnymMark

The Onym logo: a broken ring — two 46% arcs with 4% gaps, rotated −45°, stroke 16% of the diameter. Inherits `currentColor` unless `color` is set; `spin` rotates it slowly (loading/branding moments).

```tsx
<OnymMark size={64} />
<OnymMark size={40} color="var(--on-blue)" spin />
```

Maps to `OnymMark` in OnymBrand.swift. Used as the avatar placeholder and the group-avatar mark.
