# TextButton

Borderless full-width text button (44pt hit target), blue 15pt medium. `destructive` for red actions, `quiet` for muted secondary actions ("Not now").

```tsx
<TextButton icon="share">Share invite</TextButton>
<TextButton destructive>Remove relayer</TextButton>
<TextButton quiet>Not now</TextButton>
```

Maps to `SettingsTextButton`.
