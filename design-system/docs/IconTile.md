# IconTile

30×30 rounded (7pt) colored tile with a white glyph — the leading element of settings `Row`s. Colors come from the static tile palette: `purple`, `blue`, `indigo`, `orange`, `green`, `gray`, `red`, `teal`, `amber`.

```tsx
<IconTile icon="antenna" color="indigo" />
```

Usually you don't place it directly — pass `icon`/`iconColor` to `Row`. Maps to `SettingsIconTile`.
